# GTD (Getting Things Done) - Méthodologie Complète

## Introduction

Getting Things Done (GTD) est un système de productivité personnelle développé par David Allen. Le principe fondamental est que l'esprit humain est conçu pour **avoir des idées**, pas pour les stocker. En capturant tout dans un système externe de confiance, on libère son énergie mentale pour la réflexion et la prise de décision.

> "Your mind is for having ideas, not holding them." - David Allen

---

## Les 5 Étapes Fondamentales

### 1. CAPTURER (Capture)

**Objectif** : Vider son esprit de tout ce qui l'occupe.

**Principe** : Capturer TOUT ce qui traverse l'esprit - tâches, idées, événements, notes, références - dans une "inbox" (boîte de réception).

**Bonnes pratiques** :
- L'inbox peut être physique (carnet, corbeille) ou numérique (app, email)
- Ne pas organiser au moment de la capture - juste collecter
- Avoir un outil de capture toujours accessible (mobile, widget, raccourci clavier)
- Viser une capture en moins de 3 interactions

**Ce qu'on capture** :
- Emails à traiter
- Notes de réunion
- Idées spontanées
- Tâches mentionnées en conversation
- Documents à lire
- Projets potentiels

---

### 2. CLARIFIER (Clarify/Process)

**Objectif** : Transformer le chaos de l'inbox en éléments actionnables.

**Le processus de clarification** - Pour chaque élément, poser ces questions :

```
┌─────────────────────────────────────────┐
│           Qu'est-ce que c'est ?         │
└─────────────────────────────────────────┘
                    │
                    ▼
┌─────────────────────────────────────────┐
│        Est-ce actionnable ?             │
└─────────────────────────────────────────┘
        │                       │
       NON                     OUI
        │                       │
        ▼                       ▼
┌───────────────┐    ┌─────────────────────┐
│ 3 options :   │    │ Quelle est la       │
│ - Poubelle    │    │ prochaine action    │
│ - Référence   │    │ physique concrète ? │
│ - Un jour/    │    └─────────────────────┘
│   Peut-être   │               │
└───────────────┘               ▼
                    ┌─────────────────────┐
                    │ < 2 minutes ?       │
                    └─────────────────────┘
                        │           │
                       OUI         NON
                        │           │
                        ▼           ▼
                    ┌───────┐  ┌─────────────┐
                    │ FAIRE │  │ - Déléguer  │
                    │ TOUT  │  │ - Reporter  │
                    │ DE    │  │   (liste    │
                    │ SUITE │  │   d'actions)│
                    └───────┘  └─────────────┘
```

**La Règle des 2 Minutes** :
Si une action prend moins de 2 minutes, la faire immédiatement. Le temps de l'organiser et la suivre dépasserait le temps de l'exécuter.

**Règles importantes** :
- Traiter les éléments un par un, dans l'ordre
- Ne jamais remettre un élément clarifié dans l'inbox
- Vider l'inbox ne signifie pas tout finir, mais tout clarifier

---

### 3. ORGANISER (Organize)

**Objectif** : Placer chaque élément clarifié au bon endroit.

**Les listes GTD essentielles** :

#### A. Prochaines Actions (Next Actions)
- Actions concrètes, physiques, exécutables immédiatement
- Formulées avec un verbe d'action : "Appeler Jean pour...", "Rédiger le rapport de..."
- Organisées par **contexte** (voir ci-dessous)

#### B. Projets (Projects)
- Tout résultat qui nécessite plus d'une action
- Formulés comme des résultats : "Vacances d'été organisées", "Nouveau site web lancé"
- Chaque projet DOIT avoir au moins une prochaine action définie

#### C. En Attente (Waiting For)
- Actions déléguées ou dépendantes d'autrui
- Noter : quoi, à qui, depuis quand
- Exemple : "Attente réponse de Marie pour budget - envoyé 15/01"

#### D. Un Jour/Peut-être (Someday/Maybe)
- Idées non engagées mais qu'on ne veut pas perdre
- Projets potentiels futurs
- Rêves, aspirations, "ce serait bien de..."
- Revu régulièrement pour activation ou suppression

#### E. Calendrier (Calendar)
- UNIQUEMENT les engagements "hard landscape" :
  - Rendez-vous avec date/heure fixe
  - Deadlines non négociables
  - Événements
- NE PAS utiliser comme liste de rappels ou to-do

#### F. Référence (Reference)
- Informations non actionnables mais utiles
- Documents, notes, articles à conserver
- Doit être facilement retrouvable

---

### 4. Les Contextes (@Context)

**Définition** : Un contexte définit ce dont on a besoin pour exécuter une action - un lieu, un outil, une personne.

**Pourquoi les contextes ?**
- Quand on choisit quoi faire, le contexte est la première contrainte
- Inutile de voir des actions faisables uniquement au bureau si on est à la maison
- Permet de maximiser son efficacité selon la situation

**Contextes classiques** :
- `@Maison` - Actions faisables uniquement chez soi
- `@Bureau` - Actions nécessitant d'être au travail
- `@Ordinateur` - Actions nécessitant un PC
- `@Téléphone` - Appels à passer
- `@Courses` - Choses à acheter/errands
- `@EnLigne` - Nécessite connexion internet
- `@Énergie_Haute` - Tâches demandant concentration
- `@Énergie_Basse` - Tâches mécaniques/routinières
- `@Agenda:Nom` - Points à aborder avec une personne spécifique

**Conseil** : Adapter les contextes à SA réalité. Trop de contextes = friction. Pas assez = listes trop longues.

---

### 5. RÉVISER (Reflect/Review)

**Objectif** : Maintenir la confiance dans le système et rester à jour.

#### La Revue Hebdomadaire (Weekly Review)

David Allen la qualifie de **"facteur critique de succès"**.

**Durée** : 60-90 minutes, idéalement vendredi après-midi ou dimanche soir.

**Les 3 phases** :

##### GET CLEAR (Clarifier)
- [ ] Collecter les papiers/notes éparpillés
- [ ] Traiter inbox email à zéro
- [ ] Traiter inbox physique à zéro
- [ ] Vider sa tête : capturer toute pensée résiduelle

##### GET CURRENT (Actualiser)
- [ ] Revoir les actions des derniers jours sur le calendrier
- [ ] Revoir le calendrier à venir (2 semaines)
- [ ] Revoir la liste "En Attente" - relancer si nécessaire
- [ ] Revoir la liste "Projets" - chaque projet a-t-il une prochaine action ?
- [ ] Revoir les listes "Prochaines Actions" - compléter/supprimer

##### GET CREATIVE (Créer)
- [ ] Revoir la liste "Un Jour/Peut-être" - activer ou supprimer
- [ ] Y a-t-il de nouvelles idées, projets, envies ?
- [ ] Être créatif, oser noter des idées folles

---

### 6. S'ENGAGER (Engage)

**Objectif** : Faire le travail avec confiance.

**Comment choisir quoi faire ?** Utiliser ces 4 critères dans l'ordre :

1. **Contexte** : Que puis-je faire ICI avec ces OUTILS ?
2. **Temps disponible** : Combien de temps ai-je avant le prochain engagement ?
3. **Énergie** : Quel est mon niveau d'énergie/concentration ?
4. **Priorité** : Parmi les options restantes, qu'est-ce qui a le plus d'impact ?

## Les Projets en Détail

### Définition GTD d'un Projet
> "Tout résultat souhaité qui nécessite plus d'une action pour être accompli."

**Exemples** :
- "Vacances en Grèce réservées" (multi-étapes)
- "Rapport trimestriel soumis"
- "Nouvelle voiture achetée"

### Gestion des Projets

**Liste de projets** : Juste les titres (formulés comme résultats) + éventuellement description du succès.

**Prochaines actions** :
- Ne PAS lister toutes les étapes sous le projet
- Seules les prochaines actions parallèles (indépendantes) vont sur la liste Next Actions
- Les actions séquentielles : noter seulement la prochaine, les autres viendront après

**Lien Projet ↔ Actions** :
- Chaque projet doit avoir AU MOINS une prochaine action
- Les prochaines actions sont organisées par contexte, pas par projet
- Pendant la revue hebdo : vérifier ce lien

### Le Natural Planning Model (pour projets complexes)

Pour les 5% de projets nécessitant une planification formelle :

1. **But (Purpose)** : Pourquoi fait-on ce projet ?
2. **Principes** : Quelles valeurs/contraintes respecter ?
3. **Vision** : À quoi ressemble le succès ?
4. **Brainstorming** : Toutes les idées, sans filtre
5. **Organisation** : Structurer, séquencer, identifier les prochaines actions

## Les 6 Horizons de Focus

GTD propose de réfléchir à 6 niveaux, du sol au ciel :

| Horizon | Nom | Description | Fréquence de revue |
|---------|-----|-------------|-------------------|
| 0 | Actions | Prochaines actions concrètes | Quotidien |
| 1 | Projets | Résultats à court terme | Hebdomadaire |
| 2 | Domaines de responsabilité | Rôles, standards à maintenir | Mensuel |
| 3 | Objectifs (1-2 ans) | Ce qu'on veut accomplir | Trimestriel |
| 4 | Vision (3-5 ans) | Où veut-on être ? | Annuel |
| 5 | But/Raison d'être | Pourquoi existe-t-on ? | Selon besoin |

**Approche GTD** : Commencer par le bas (maîtriser les actions) avant de monter. Difficile de réfléchir à sa vision si on est submergé par les emails.

## Implications UX pour une App GTD

### Capture
- **Ultra-rapide** : < 3 secondes pour noter une pensée
- **Omniprésent** : Widget, raccourci clavier, Siri/voix, email-to-inbox
- **Minimal** : Juste le titre suffit au départ
- **Sans friction** : Pas de choix de projet/contexte à la capture

### Clarification
- **Guidée** : Wizard avec les questions GTD
- **Règle 2 min** : Timer optionnel
- **Flux continu** : Passer facilement d'un item au suivant
- **Décisions rapides** : Boutons pour Poubelle/Référence/Un jour

### Organisation
- **Contextes faciles** : Tags, pas de hiérarchie complexe
- **Projets visibles** : Voir si un projet n'a pas de prochaine action
- **Vues multiples** : Par contexte, par projet, par date

### Revue
- **Checklist intégrée** : Guide de revue hebdo
- **Métriques** : Inbox zero streak, projets sans action, etc.
- **Rappel** : Notification pour la revue hebdo

### Engagement
- **Focus** : Afficher peu d'actions à la fois
- **Filtre contexte** : Un tap pour voir "@Bureau" seulement
- **Quick complete** : Swipe pour terminer

---

## Pièges Courants à Éviter

1. **Utiliser le calendrier comme to-do** : Le calendrier = engagements fixes uniquement
2. **Trop de contextes** : Créer de la friction inutile
3. **Projets = tâches** : Un projet n'est pas une grosse tâche, c'est un résultat
4. **Sauter la revue hebdo** : Le système s'effondre sans elle
5. **Capturer mais pas clarifier** : Inbox qui déborde = stress
6. **Actions vagues** : "Truc pour le rapport" vs "Appeler Marie pour les chiffres Q3"
7. **Ne pas faire les 2 minutes** : Accumuler des micro-tâches
