```
Button with shortcut:
┌─────────────────┐
│  Yes [Y]        │
└─────────────────┘

Navigation tab with shortcut:
┌─────────────────┐
│  📥 Inbox (3)   │
│      g i        │  (shown on hover or always)
└─────────────────┘

Footer shortcuts bar:
────────────────────────────────────────────────────────────────
[↑/↓] Navigate  [c] Complete  [e] Edit  [m] Move  [/] Search
```
