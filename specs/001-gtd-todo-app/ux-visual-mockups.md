## Interactions Clés

### Compléter une Tâche

```
AVANT:                                 APRÈS (animation):
┌────────────────────────────┐        ┌────────────────────────────┐
│ ☐  Appeler plombier        │  →→→   │ ✓  Appeler plombier ~~~~   │  →→→  (disparaît)
│    @Tel  📅 Demain         │        │    @Tel  📅 Demain  ✨     │
└────────────────────────────┘        └────────────────────────────┘
                                              ↓
                                        Toast: "Tâche terminée! 🎉"
```

### Swipe Actions (Mobile)

```
← Swipe gauche:                        Swipe droite: →
┌────────────────────────────┐        ┌────────────────────────────┐
│ 🗑️ SUPPRIMER │ ☐ Tâche... │        │ ...Tâche ☐ │ ✓ TERMINER   │
│    Rouge     │             │        │             │    Vert      │
└────────────────────────────┘        └────────────────────────────┘
```

### Drag & Drop (Desktop)

```
Réorganiser les tâches:

┌────────────────────────────┐

├────────────────────────────┤
│ ⋮⋮  ☐  Tâche 2             │  ← Glisser ici
├┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┤     (drop zone)
│ ⋮⋮  ☐  Tâche 3 [DRAGGING]  │  ← En cours de déplacement
├────────────────────────────┤
│ ⋮⋮  ☐  Tâche 4             │
└────────────────────────────┘
```

## Résumé des Écrans

| Écran | Route | Description |
|-------|-------|-------------|
| Inbox | `/inbox` | Capture + liste avec bouton Clarifier par item |
| Clarify Panel | (overlay) | Panneau latéral de clarification inline |
| Actions | `/actions` | Vue unifiée avec sections repliables + filtres |
| Actions filtrées | `/actions?context=X` | Filtre actif visible |
| Projet détail | `/projects/:id` | Vue projet avec ses tâches |
| Settings: Compte | `/settings/account` | Profil, préférences |
| Settings: Contextes | `/settings/contexts` | CRUD contextes |
| Settings: Projets | `/settings/projects` | Liste projets + actions |
